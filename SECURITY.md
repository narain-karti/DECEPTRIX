# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or algorithmic integrity flaw in DECEPTRIX:
1. Please **do not** create a public GitHub issue.
2. Email the core team or project maintainers with reproduction steps and media samples.
3. Vulnerabilities will be triaged and addressed within 48 hours.
